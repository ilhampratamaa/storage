Akses StorageQR dari HP

Pastikan HP terhubung ke Wi-Fi yang sama dengan komputer server.

1. Unduh sertifikat HTTPS 2. Buka StorageQR
Penting: kamera live hanya bisa dipakai melalui HTTPS dan sertifikat harus dipercaya oleh HP. Jika belum memasang sertifikat, gunakan tombol pertama terlebih dahulu.

Android

  1. Unduh sertifikat di atas.
  2. Buka Settings → Security/Privacy → Install certificate → CA certificate. Nama menu dapat sedikit berbeda tiap merek.
  3. Pilih file storage-lan.crt, lalu konfirmasi.
  4. Buka URL HTTPS dan izinkan kamera.

iPhone/iPad

  1. Unduh sertifikat menggunakan Safari.
  2. Buka Settings → Profile Downloaded, lalu Install.
  3. Buka Settings → General → About → Certificate Trust Settings, aktifkan trust untuk sertifikat StorageQR.
  4. Buka URL HTTPS dan izinkan kamera.

Jika halaman HTTP ini tidak bisa dibuka, jalankan Apache/XAMPP sebagai Administrator atau izinkan Apache pada Windows Firewall untuk jaringan Private, port TCP 80 dan 443.
